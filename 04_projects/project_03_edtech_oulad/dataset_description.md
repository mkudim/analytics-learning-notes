# Open University Learning Analytics dataset (OULAD)

[SOURCE](https://analyse.kmi.open.ac.uk/open-dataset)

Эта страница представляет анонимизированный набор данных Open University Learning Analytics Dataset (OULAD). Он содержит данные о курсах, студентах и их взаимодействии с виртуальной средой обучения (Virtual Learning Environment, VLE) для семи выбранных курсов (здесь они называются модулями). Запуски курсов начинаются в феврале и октябре — они помечены буквами «B» и «J» соответственно. Набор данных состоит из таблиц, связанных между собой с помощью уникальных идентификаторов. Все таблицы хранятся в формате CSV.

## courses.csv
Файл содержит список всех доступных модулей и их презентаций. В нём представлены следующие столбцы:

* code_module — кодовое название модуля, которое служит идентификатором.
* code_presentation — кодовое название презентации. Оно состоит из года и буквы «B» для презентации, начинающейся в феврале, и буквы «J» для презентации, начинающейся в октябре.
* length — продолжительность связки модуль-презентация в днях.

Структура презентаций B и J может различаться, поэтому хорошей практикой считается анализировать презентации B и J отдельно. Тем не менее для некоторых презентаций соответствующая предыдущая презентация B/J отсутствует, поэтому для анализа презентации J приходится использовать данные презентации B, и наоборот. В этом датасете это относится к модулям CCC, EEE и GGG.

## assessments.csv
Этот файл содержит информацию об оценочных мероприятиях в рамках связок модуль-презентация. Обычно каждая презентация включает несколько оценочных мероприятий, за которыми следует итоговый экзамен. CSV-файл содержит следующие столбцы:

* code_module — идентификационный код модуля, к которому относится оценочное мероприятие.
* code_presentation — идентификационный код презентации, к которой относится оценочное мероприятие.
* id_assessment — идентификационный номер оценочного мероприятия.
* assessment_type — тип оценочного мероприятия. Существуют три типа: Tutor Marked Assessment (TMA), Computer Marked Assessment (CMA) и Final Exam (Exam).
* date — информация о крайнем сроке сдачи оценочного мероприятия, рассчитанном как количество дней с начала связки модуль-презентация. Дата начала презентации имеет номер 0 (ноль).
* weight — вес оценочного мероприятия в процентах. Обычно экзамены рассматриваются отдельно и имеют вес 100%; сумма всех остальных оценочных мероприятий также составляет 100%.

Если информация о дате итогового экзамена отсутствует, считается, что он проходит в конце последней недели презентации.

## vle.csv
CSV-файл содержит информацию о доступных материалах в VLE. Обычно это HTML-страницы, PDF-файлы и т. п. Студенты имеют доступ к этим материалам онлайн, а их взаимодействия с материалами записываются.
Файл vle.csv содержит следующие столбцы:

* id_site — идентификационный номер материала.
* code_module — идентификационный код модуля.
* code_presentation — идентификационный код презентации.
* activity_type — роль, связанная с материалом модуля.
* week_from — неделя, с которой материал планируется использовать.
* week_to — неделя, до которой материал планируется использовать.

## studentInfo.csv
Этот файл содержит демографическую информацию о студентах вместе с их результатами. Файл содержит следующие столбцы:

* code_module — идентификационный код модуля, на который зачислен студент.
* code_presentation — идентификационный код презентации, в рамках которой студент зачислен на модуль.
* id_student — уникальный идентификационный номер студента.
* gender — пол студента.
* region — географический регион, в котором проживал студент во время прохождения связки модуль-презентация.
* highest_education — наивысший уровень образования студента на момент начала обучения по презентации модуля.
* imd_band — категория по индексу множественной депривации места, где студент проживал во время прохождения связки модуль-презентация.
* age_band — возрастная категория студента.
* num_of_prev_attempts — количество предыдущих попыток прохождения этого модуля.
* studied_credits — общее количество кредитов по модулям, которые студент изучает в данный момент.
* disability — указывает, заявил ли студент о наличии инвалидности.
* final_result — итоговый результат студента по связке модуль-презентация.

## studentRegistration.csv
Этот файл содержит информацию о времени регистрации студента на презентацию модуля. Для студентов, отменивших регистрацию, также записана дата отмены. Файл содержит пять столбцов:

* code_module — идентификационный код модуля.
* code_presentation — идентификационный код презентации.
* id_student — уникальный идентификационный номер студента.
* date_registration — дата регистрации студента на презентацию модуля; это количество дней, измеренное относительно начала связки модуль-презентация. Например, отрицательное значение -30 означает, что студент зарегистрировался на презентацию модуля за 30 дней до её начала.
* date_unregistration — дата отмены регистрации студента на презентацию модуля; это количество дней, измеренное относительно начала связки модуль-презентация. У студентов, завершивших курс, это поле пустое. У студентов, отменивших регистрацию, в столбце final_result файла studentInfo.csv указано значение Withdrawal.

## studentAssessment.csv
Этот файл содержит результаты оценочных мероприятий студентов. Если студент не сдаёт оценочное мероприятие, результат не записывается. Данные о сдаче итогового экзамена отсутствуют, если результаты оценивания не хранятся в системе.
Файл содержит следующие столбцы:

* id_assessment — идентификационный номер оценочного мероприятия.
* id_student — уникальный идентификационный номер студента.
* date_submitted — дата сдачи работы студентом, измеряемая как количество дней с начала презентации модуля.
* is_banked — статусный флаг, указывающий, что результат оценочного мероприятия был перенесён из предыдущей презентации.
* score — балл студента за это оценочное мероприятие. Диапазон значений — от 0 до 100. Балл ниже 40 интерпретируется как Fail. Оценки находятся в диапазоне от 0 до 100.

## studentVle.csv
Файл studentVle.csv содержит информацию о взаимодействиях каждого студента с материалами в VLE.
Файл содержит следующие столбцы:

* code_module — идентификационный код модуля.
* code_presentation — идентификационный код презентации модуля.
* id_student — уникальный идентификационный номер студента.
* id_site — идентификационный номер материала VLE.
* date — дата взаимодействия студента с материалом, измеряемая как количество дней с начала связки модуль-презентация.
* sum_click — количество раз, когда студент взаимодействовал с материалом в этот день.
