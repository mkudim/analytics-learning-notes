# Executive Dashboard: E-commerce Funnel (Sportmaster)

## Назначение дашборда

Дашборд предназначен для **executive-уровня (CEO / Head of Product / Head of E-commerce)**
и отвечает на ключевой вопрос:

**Как бизнес чувствует себя сегодня по сравнению со вчерашним днём?**

Фокус сделан на:
* конечный бизнес-результат (заказы),
* активность пользователей,
* эффективность воронки продаж.

Дашборд не перегружен деталями и предназначен для **быстрого ежедневного просмотра**.

---

## Используемые данные

Источник данных:
- PostgreSQL
- Представление `dm.events_v`

Уровень детализации:
- event-level данные
- агрегация до day-level внутри BI-инструмента

Период анализа:
- 01.06.2024 – 20.06.2024
(21.06.2024 исключён из анализа из-за неполного дня)

---

## Структура дашборда

Дашборд состоит из **4 ключевых KPI-карточек**, расположенных в логике бизнес-воронки:

1. **Orders**
2. **Users**
3. **CR View → Cart**
4. **CR View → Order**

Каждая карточка:
- показывает значение за **последний полный день**,
- содержит **сравнение с предыдущим днём** (day-over-day).

---

## Описание метрик

### 1. Orders

**Что показывает:**
Количество оформленных заказов за день.

**Бизнес-смысл:**
Основной итоговый KPI e-commerce.
Используется для оценки общего состояния бизнеса и динамики продаж.

**Логика расчёта:**
```
Orders = SUM(Create Order = true)
```

**Сравнение:**

с предыдущим днём (day-over-day)

### 2. Users

**Что показывает:**
Количество уникальных пользователей, совершивших хотя бы одно событие за день.

**Бизнес-смысл:**
Показывает фактический объём пользовательского трафика и интерес к продукту.

**Логика расчёта:**
```
Users = COUNT(DISTINCT user_id)
```

**Сравнение:**

с предыдущим днём (day-over-day)

### 3. CR View → Cart

**Что показывает:**
Конверсию из просмотров в добавление товара в корзину.

**Бизнес-смысл:**
Характеризует качество:
* ассортимента,
* карточек товаров,
* ценового предложения.

Хорошо реагирует на изменения в контенте и UX.

**Логика расчёта:**
```
CR View → Cart = Add to Cart / Views
```

*где:*

Add to Cart — количество событий добавления в корзину

Views — общее количество событий (просмотров)

**Сравнение:**

с предыдущим днём (day-over-day)

### 4. CR View → Order

**Что показывает:**
Сквозную конверсию из просмотра в оформленный заказ.

**Бизнес-смысл:**
Интегральная метрика эффективности всей воронки:
* от интереса пользователя
* до финального бизнес-результата

Используется для оценки общего «здоровья» e-commerce.

**Логика расчёта:**
```
CR View → Order = Orders / Views
```

**Сравнение:**

с предыдущим днём (day-over-day)

---

## Почему выбран формат «последний день + сравнение»

Для executive-дашборда выбран именно этот подход, потому что он позволяет:
* быстро понять текущее состояние бизнеса,
* сразу увидеть позитивную или негативную динамику,
* не перегружать экран историческими графиками.

Анализ за длинные периоды и сегментация по каналам/категориям
вынесены за рамки данного дашборда и предполагаются
как следующий уровень аналитики.

## Ограничения и допущения

Последний день данных (21.06.2024) исключён из анализа из-за неполной загрузки событий.

Все конверсии считаются на уровне событий, а не уникальных пользователей.

Дашборд не учитывает:
* выручку,
* средний чек,
* маркетинговые каналы.

## Возможности развития

Потенциальные направления расширения дашборда:
* добавление Revenue и AOV,
